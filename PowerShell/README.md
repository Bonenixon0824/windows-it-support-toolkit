# PowerShell Scripts

This folder contains PowerShell scripts created to automate common Windows administration, troubleshooting, and IT support tasks.

---

## Available Scripts

| Script | Description |
|---------|-------------|
| system-info.ps1 | Displays computer hardware, operating system, processor, RAM, and current user information. |
| network-info.ps1 | Displays IP configuration, DNS servers, and network adapter details. |
| disk-cleanup.ps1 | Removes temporary Windows files to help free disk space. |
| running-services.ps1 | Lists all currently running Windows services. |
| installed-software.ps1 | Displays installed software from the Windows registry. |
| event-log-review.ps1 | Displays recent Windows System event log errors. |
| windows-update-check.ps1 | Checks the Windows Update service status. |
